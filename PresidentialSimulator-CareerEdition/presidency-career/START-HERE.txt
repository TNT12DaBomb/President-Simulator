PRESIDENTIAL SIMULATOR — CAREER EDITION

WINDOWS

1. Extract the full ZIP into a normal folder.
2. Open the presidency-career folder.
3. Double-click run-windows.bat.
4. Choose Start a new career and use the numbered menus.

The included career.jar needs Java 17 or newer. You do not need to type
terminal commands to play. The game provides menus for saving, loading,
help, developer tools, and exiting.

THE CAREER LOOP

Campaign for 16 turns. If you win, review the election, complete a transition,
then govern through sixteen quarterly decisions. A normal career allows two
elected four-year terms, including nonconsecutive terms. If you lose, the loss
stays on your record and a four-year comeback period opens before you can run
again. Donor meetings, campaign review, and community work change what carries
into your next campaign.

Your campaign cash and the presidential treasury are separate. Career Status
shows public feedback, reputation, organizational support, economy/operating
cash, election history, and next-campaign effects.

MENUS

The 0 option reaches the Game Menu from every major screen. Use it for:
- Save and load, including three manual slots
- Help
- Developer tools
- Save and return to the title
- Save and exit

While an event is waiting for a response, 0 opens the same game menu. A pending
response is preserved by the autosave.

DEVELOPER TOOLS

Developer scenarios can force a campaign outcome, jump into the first or second
term, open the reelection campaign, add campaign or treasury cash, or finish a
term with routine quarters. Developer use is written into the save and marked
on the career status. These tools exist to make later content and GUI work easy
to test; they are not normal gameplay.

IF YOU EDIT THE SOURCE

Keep all production Java files together. Run build-windows.bat on Windows or
sh build.sh on Mac/Linux. Building requires a JDK 17 or newer. The source has a
separate CareerEngine and UI-independent GameEngine so a future GUI can use the
same CareerCommand and CareerView objects.
